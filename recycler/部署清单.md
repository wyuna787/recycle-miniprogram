# 部署清单

二手电子设备回收交易平台 MVP 上线前部署准备清单（后端 + 小程序前端）。

---

## 一、云服务器准备

| 项目 | 建议 |
|------|------|
| 操作系统 | Ubuntu 22.04 LTS 或 CentOS 7/8 |
| Python | 3.10 或 3.11 |
| 反向代理 | Nginx |
| 证书 | HTTPS（Let's Encrypt 或云厂商证书） |
| 域名 | 至少 1 个 API 域名，例如 `api.example.com` |

---

## 二、后端部署步骤

### 1. 上传代码

将 `recycler` 目录上传至服务器，例如：

```text
/opt/recycler/
```

需包含：`main.py`、`models.py`、`database.py`、`auth.py`、`requirements.txt` 等全部后端文件。

### 2. 创建虚拟环境并安装依赖

```bash
cd /opt/recycler
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. 启动服务（验证）

```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```

浏览器或 curl 访问：

```text
https://api.example.com/docs
```

（生产环境建议 Nginx 反代 + HTTPS，见下。）

### 4. Nginx 反向代理（示例）

```nginx
server {
    listen 443 ssl;
    server_name api.example.com;

    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 5. 进程守护（二选一）

**systemd 示例**（`/etc/systemd/system/recycler.service`）：

```ini
[Unit]
Description=Recycler FastAPI
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/recycler
Environment="PATH=/opt/recycler/.venv/bin"
ExecStart=/opt/recycler/.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable recycler
sudo systemctl start recycler
```

**supervisor** 亦可，配置 `command` 指向同上 uvicorn 命令。

### 6. 初始化测试数据（可选，仅测试环境）

```bash
curl -X POST https://api.example.com/dev/init
```

生产环境建议限制或关闭 `/dev/init` 访问。

## 三、小程序前端准备

前端项目目录（本地示例）：

```text
~/Desktop/order dishes/二手商城交易平台/
```

### 1. 修改 API 地址

编辑 `utils/request.js`：

```js
const BASE_URL = 'https://api.example.com'
```

必须使用 **HTTPS**，且与微信公众平台配置的合法域名一致。

### 2. 微信公众平台配置

登录 [微信公众平台](https://mp.weixin.qq.com/) → 开发 → 开发管理 → 开发设置：

- **服务器域名** → request 合法域名：添加 `https://api.example.com`
- 上传代码前在开发者工具中关闭「不校验合法域名」（仅本地调试时可临时开启）

### 3. 编译与上传

1. 使用 HBuilderX 或微信开发者工具打开 uni-app 项目
2. 发行 → 小程序-微信
3. 上传体验版 / 提交审核

## 四、数据库说明

| 阶段 | 方案 |
|------|------|
| 开发 | SQLite，文件 `recycle.db` |
| 上线初期小规模试运行 | 可继续使用 SQLite |
| 业务增长 | 迁移 MySQL，需调整 `database.py` 中 `DATABASE_URL` |

**上线前必须备份** `recycle.db`：

```bash
cp recycle.db recycle.db.bak.$(date +%Y%m%d)
```

建议配置定时备份（cron + 对象存储）。

## 五、上线前检查清单

### 后端

- [ ] `https://api.example.com/docs` 可访问
- [ ] `POST /api/account/login` 测试账号可登录
- [ ] `GET /api/admin/trades` 平台管理员 token 可返回交易流
- [ ] `/dev/init` 已在生产环境禁用或限 IP（如仍保留）
- [ ] `recycle.db` 已备份
- [ ] systemd/supervisor 进程守护正常，重启服务器后服务自启

### 小程序

- [ ] `BASE_URL` 已改为正式 HTTPS 域名
- [ ] 微信公众平台 request 合法域名已配置
- [ ] 登录页可正常登录（30001 / 10001 / 20001 或正式账号）
- [ ] 商家发布设备 → 回收商报价 → 确认报价 → 生成订单
- [ ] 商家发货 → 回收商签收 → 验机 → 商家确认/申诉
- [ ] 平台订单监控可看到全链路状态
- [ ] 401 时提示「登录已失效，请重新登录」

### 安全（建议）

- [ ] 修改 `auth.py` 中 `SECRET_KEY` 为强随机字符串（生产必做）
- [ ] 关闭或保护 `/dev/init`
- [ ] 防火墙仅开放 80/443，8000 仅本机或内网访问

## 六、本地自测命令速查

```bash
# 后端
cd ~/Desktop/recycler && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 初始化
curl -X POST http://127.0.0.1:8000/dev/init

# 登录测试
curl -X POST http://127.0.0.1:8000/api/account/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"10001","password":"111"}'
```

微信开发者工具：本地 `BASE_URL` 保持 `http://127.0.0.1:8000`，勾选不校验合法域名。
